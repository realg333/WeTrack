# WeTrack — instruções do projeto

## Publicação

Preferência permanente do usuário, registrada em 19/10/2026: após concluir e validar uma alteração, sempre fazer commit e push para a branch de produção `main` de `origin` (`realg333/WeTrack`) para acionar o deploy automático da Vercel. Essa publicação já está autorizada; não encerrar o trabalho apenas com a implementação local nem pedir nova confirmação para publicar as alterações solicitadas.

Acompanhar o deploy automático do projeto `wetrack` e verificar o site de produção em `https://wetrack-psi.vercel.app`. Informar se houver falha ou bloqueio que impeça a publicação.

Publicar somente as alterações do trabalho em andamento. Preservar alterações de outras tarefas que compartilhem o checkout e nunca incluir credenciais, arquivos `.env`, banco local ou dados privados nos commits.
